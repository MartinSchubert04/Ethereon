# Fonts

| File | Font | Author | License |
|---|---|---|---|

| `SymbolsNerdFontMono-Regular.ttf` | Symbols Nerd Font Mono 3.5.1 (Nerd Fonts icons only) | Ryan L McIntyre and contributors | MIT |

Jacquard 24 (OFL) comes from the `@fontsource/jacquard-24` package; Inter and Geist Mono (OFL), from
`@fontsource-variable/*`. The Athanor theme uses them; the other themes use Inter and Geist Mono.

For the terminal you can also choose JetBrains Mono, Fira Code, IBM Plex Mono, Source Code Pro and
Cascadia Mono (OFL, from `@fontsource/*`, latin 400 and 700 only) or any font installed on
Windows. Symbols Nerd Font Mono is always the fallback for icons (see
`src/styles/term-fonts.css`).
