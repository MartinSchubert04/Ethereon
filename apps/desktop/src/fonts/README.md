Jacquard 24 (OFL) viene del paquete `@fontsource/jacquard-24`; Inter y Geist Mono (OFL), de
`@fontsource-variable/*`. Las usa el tema Athanor; los demás temas usan Inter y Geist Mono.

Para la terminal se pueden elegir además JetBrains Mono, Fira Code, IBM Plex Mono, Source Code Pro y
Cascadia Mono (OFL, de `@fontsource/*`, solo latin 400 y 700) o cualquier fuente instalada en
Windows. Symbols Nerd Font Mono va siempre de respaldo para los iconos (ver
`src/styles/term-fonts.css`).
